# Sorting Visualizer

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Status: Active](https://img.shields.io/badge/Status-Active-success.svg)

**Sorting Visualizer** — это интерактивное веб-приложение для визуализации алгоритмов сортировки, созданное для демонстрации работы различных методов упорядочивания данных в реальном времени. Проект выполнен в современном дизайне с использованием плавных анимаций и подсветки кода.

## 🚀 Возможности

*   **Визуализация алгоритмов**:
    *   Bubble Sort (Сортировка пузырьком)
    *   Selection Sort (Сортировка выбором)
    *   Insertion Sort (Сортировка ставками)
    *   Merge Sort (Сортировка слиянием)
    *   Quick Sort (Быстрая сортировка)
*   **Интерактивное управление**:
    *   Запуск, Пауза, Пошаговое выполнение, Сброс.
    *   Регулировка размера массива (от 5 до 50 элементов).
    *   Регулировка скорости анимации (от 10ms до 500ms).
*   **Режимы отображения**:
    *   **Столбики**: Классическая диаграмма.
    *   **Цифры**: Числовое представление для детального анализа.
*   **Образовательный аспект**:
    *   Подсветка выполняемых строк кода в реальном времени.
    *   Отображение сложности алгоритма (Big O).
    *   Счетчики сравнений и обменов.
    *   Цветовая легенда для понимания текущих операций (Сравнение, Обмен, Опорный элемент).

## 🛠 Технологии

*   **HTML5**: Семантическая структура.
*   **CSS3**: Ванильный CSS, Flexbox, Grid, CSS Variables для темизации. Используются шрифты *JetBrains Mono* и *Inter*.
*   **JavaScript (ES6+)**: Логика сортировки и управления DOM без использования сторонних фреймворков.

## 📦 Установка и Запуск

Вы можете запустить проект локально или просмотреть его онлайн (если развернут).

### Локальный запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/markdip/sort-simulation.git
    ```
2.  Перейдите в папку проекта:
    ```bash
    cd sort-simulation
    ```
3.  Откройте файл `index.html` в вашем браузере.

### Развертывание (GitHub Pages)

Этот проект настроен для автоматического развертывания на GitHub Pages.
Просто запушьте изменения в ветку `main`, и сайт будет доступен по адресу `https://markdip.github.io/sort-simulation/`.
